# 极光影院 (Aurora Player) 产品需求规格说明书 (PRD)

## 1. 产品定位与目标
极光影院（Aurora Player）是一款基于 **Tauri 2.x (Rust) + React 19 + TypeScript + Hls.js** 架构构建的高性能、现代化流媒体视频播放客户端。
- **核心定位**：媲美主流商业视频 App（爱优腾、B站、IINA）的原生级跨端流媒体客户端。
- **核心价值**：
  1. 通过 Rust 本地微代理绕过防盗链、重写 M3U8 并实时剥离图片伪装头，实现秒播无黑屏。
  2. 极致低内存占用（~40MB RAM），启动迅速，体验丝滑。
  3. 提供全套原生级播放交互（手势调节、续播定位、AirPlay、离线缓存与多源聚合）。

---

## 2. 系统核心架构与技术选型

| 层次 | 技术栈 | 职责与能力 |
| :--- | :--- | :--- |
| **桌面运行时** | **Tauri 2.x (Rust)** | 轻量原生窗口、系统事件拦截、原生文件系统沙盒与低开销运行 |
| **本地流代理** | **Tokio + Axum + Reqwest** | 监听本地随机端口，重写 M3U8 分片地址，剥离图片前缀（`0x47` TS 还原） |
| **UI 与交互** | **React 19 + TypeScript + Vite** | 现代化深色主题流媒体交互、多级筛选、横屏全屏沉浸视口 |
| **播放内核** | **Hls.js + HTML5 Video** | 自适应码率、硬件解码加速、分片缓存、网络重试策略 |

## 3. 核心功能需求定义

### 3.1 视频播放内核与本地代理
- **防盗链清洗**：动态注入上游请求头（User-Agent、Referer）。
- **切片伪装清洗**：自动剔除 PNG/JPEG/GIF 伪装头部，还原纯净 MPEG-TS 切片流。
- **双播放模式**：
  - `LocalProxy`：走本地 Rust 代理处理特殊防盗链源。
  - `Direct`：对公开 CDN 源直接播放，降低代理损耗。

### 3.2 全屏触控手势系统 (Phase 1 首要)
- **屏幕左侧边缘右滑（复刻 iPhone 原生手势）**：
  - **触发条件**：在视频播放（竖屏详情或横屏全屏模式）时，从屏幕最左侧边缘（起始 $X \le 40\text{px}$）向右滑动手势生效。
  - **交互行为**：与 iPhone 系统级侧滑返回体验完全一致，触发“返回上一步”（级联关闭：集数抽屉 $\rightarrow$ 退出横屏全屏 $\rightarrow$ 退出播放返回影视列表）。
  - **防误触隔离**：与屏幕中央区域的快进/快退水平拖拽（Seek 手势）物理隔离，互不干扰。
- **左半屏垂直滑动**：连续平滑调节屏幕亮度（0% ~ 100%），带有垂直柱状太阳胶囊 HUD。
- **右半屏垂直滑动**：调节视频真实音量（0% ~ 100%），联动静音图标切换。
- **中央水平横滑**：时间进度快速拖拽预览，显示 `[ 当前时间 / 总时长 ] (步进偏移)`，松手触发精确 Seek。
- **任意位置长按**：无缝切换为 2.0x 高速播放，顶部浮现 `▶▶ 2.0x` 呼吸徽章，松手即刻恢复原倍速。

### 3.3 追剧收藏与用户中心 (Phase 2)
- **本地收藏库**：支持剧集一键收藏，数据持久化于本地存储。
- **更新提醒**：比对当前观看集数与源站最新集数，若有新增自动显示“有更新”角标。
- **我的追剧抽屉**：半透明毛玻璃抽屉面板，支持快捷续播、删除与排序。

### 3.4 投屏与多画幅适配 (Phase 3)
- **AirPlay 投屏**：集成 WebKit 原生投屏协议（`webkitShowPlaybackTargetPicker`）。
- **画幅比例切换**：支持自适应黑边（Contain）、铺满消除黑边（Fill）、居中裁剪（Cover）。
- **屏幕锁**：全屏时一键锁定触控，防止手掌误触。

### 3.5 离线缓存引擎 (Phase 4)
- **M3U8 切片下载**：后台多线程并发下载分片并拼装缓存。
- **断网起播**：在无网络环境下自动拦截并转为本地 blob/file 播放。

### 3.6 自定义源扩展 (Phase 5)
- **CMS / JSON 源接入**：支持 TVBox 格式接口导入与多线路测速。

---

## 4. 非功能性需求与性能指标
- **起播延迟**：首帧起播时间 $\le 800\text{ms}$。
- **内存占用**：静默状态下内存占用 $\le 50\text{MB}$，4K 播放时 $\le 150\text{MB}$。
- **交互帧率**：手势滑动与 UI 动效稳定在 60 FPS 无掉帧。
- **无障碍与平台适配**：完整适配 macOS、iOS Web 及主流移动端视口。
